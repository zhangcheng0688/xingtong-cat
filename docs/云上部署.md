# 云上部署指南（生产环境）

> 结论先行：**一台 4 核 8G、60GB 硬盘的云服务器，就能跑起整个产品**——
> Next.js 应用（多专家 Agent + 语音 + 积分）+ RAGFlow 检索引擎 + Caddy 自动 HTTPS。
> 全部组件已容器化，脚本已备好，你只需「买服务器 → 跑一个脚本 → 填密钥 → 启动」。

## 一、架构

```
微信小程序 / 浏览器
        │  HTTPS（已备案域名）
        ▼
┌─ 云服务器 4C8G ─────────────────────────────┐
│  Caddy :80/:443  自动签发/续期 HTTPS 证书    │
│    └─► app (Next.js) :3000                  │
│          ├─► 阿里百炼网关（大脑/ASR/TTS/向量）│  ← 外网，你的 sk-ws Key
│          └─► ragflow :9380（容器内网）        │
│                ├─ es01（向量索引）            │
│                ├─ mysql / minio / redis      │
└─────────────────────────────────────────────┘
```

- RAGFlow **不对公网开放**，管理后台走 SSH 隧道（`ssh -L 9380:localhost:9380`），安全。
- 大模型调用从云服务器直连百炼北京网关，同地域低延迟。

## 二、云厂商选型（2026-08 判断）

| 厂商 | 可行性 | 说明 |
|---|---|---|
| **阿里云** | ✅ 推荐 | 与百炼网关同云同地域，延迟最低；个人可买；ICP 备案最成熟 |
| **腾讯云** | ✅ 推荐 | 与微信生态对接资料多；同样个人可买、可备案 |
| **AWS 中国（宁夏/北京）** | ⚠️ 可以但重 | 需企业主体，备案走光环新网/西云数据，周期长 |
| **AWS 海外** | ❌ 排除 | 无法 ICP 备案，小程序合法域名通不过 |

**规格建议**：4 核 8G + 60GB ESSD + 5Mbps 带宽。
成本量级（估算，以下单页实际价格为准）：包年约 ¥1000–2500/年（各家活动价差异大）；学生/新用户首单通常更低。

## 三、部署步骤（约 30 分钟）

1. **买服务器**：Ubuntu 24.04，4C8G，记下公网 IP。安全组放行 22/80/443。
2. **域名备案 + 解析**：如 `api.你的域名.com` A 记录指向服务器 IP。
   （备案需在买服务器的厂商处提交，周期 3–20 个工作日，早启动）
3. **一键初始化**：
   ```bash
   ssh root@你的IP 'bash -s' < infra/cloud/bootstrap.sh
   ```
   脚本会做：装 Docker、配镜像加速器、ES 内核参数、4G Swap、防火墙、拉代码。
4. **填密钥**：`cd /opt/xingtong-cat && cp .env.example .env.production`，
   填入百炼 Key、语音模型、`KNOWLEDGE_BACKEND=ragflow`、`RAGFLOW_BASE_URL=http://ragflow:9380`、`DOMAIN=api.你的域名.com`。
5. **启动**：
   ```bash
   docker compose -f infra/docker-compose.prod.yml --env-file .env.production up -d --build
   ```
6. **初始化 RAGFlow**（一次性）：SSH 隧道打开 `http://localhost:9380`，
   按 [RAGFlow接入.md](RAGFlow接入.md) 第二~四步配百炼 embedding → 建库传 10 篇知识 → 拿
   `RAGFLOW_API_KEY` / `RAGFLOW_DATASET_ID` 回填 `.env.production`，再 `up -d` 一次。
7. **验证**：`curl https://api.你的域名.com/api/health`（或任一 API），
   小程序后台把 `https://api.你的域名.com` 加入 request 合法域名。

## 四、之后的日常发布：push 即部署

`.github/workflows/deploy.yml` 已备好：在仓库 Secrets 配 `SERVER_HOST` /
`SERVER_USER` / `SERVER_SSH_KEY` 三个值后，**每次 push 到 main 自动上线**。

## 五、容量与扩展（什么时候要加机器）

- 当前形态支撑：日活几百家庭无压力（瓶颈在百炼网关 QPS，不在服务器）。
- 信号：CPU 持续 >70% 或 ES 内存告警 → 先升 8C16G；再往上把 RAGFlow 拆到独立机器，
  应用与检索分离（compose 已按服务拆分，拆开只需改 `RAGFLOW_BASE_URL`）。
- 数据层：M2 把 JSON store 迁 Postgres 时，可同机加一个 postgres 容器或直接用云 RDS。

## 六、本机与云的关系

- 本机 colima（已装好）= 开发备用环境，随时 `colima start` 就能本地调 RAGFlow。
- 云服务器 = 生产。代码两边一致，差异只在 `.env`。
