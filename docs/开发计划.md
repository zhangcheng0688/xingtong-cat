## 五、关于 LangChain（结论：不用，底座已经有了）

我们的编排层是**自己写的、可读的 400 行代码**（`lib/agents.ts`），不是黑盒：

- **固定管线编排**：`createSession` 串行（场景理解 → 检索 → 开场白），`runTurn` 并行（儿童模拟者 + 观察专家 `Promise.all`）——流程是确定的，不需要 LangChain 的动态链式路由
- **结构化输出契约**：每个 Agent 强制 `response_format: json_object` + `extractJson` 兜底解析（围栏 → 首尾花括号截取）
- **字段级校验**：`toyChat` 对 emotion 做枚举白名单、对缺字段给默认值，安全红线 alert 独立成字段
- **上下文窗口管理**：历史对话截断（演练 12 条 / 玩具 10 条）防 token 爆炸
- **可换网关证明架构有效**：模型和 Base URL 全走环境变量，kimi-k3 ↔ 千问一键切换已实测

稳定性真正缺的不是 LangChain，而是 **M1 里的重试/超时/降级链** 和 **M3 的调用埋点**——这两块已排进路线图，补上就是完整底座。
