# 星童猫咪 · AI 驱动的自闭症家庭干预伙伴（V1.1）

让每个家庭都请得起一位「懂孩子的干预专家」。本仓库是融资路演材料中**第一步（软件）**的完整可运行产品，
按微信小程序形态设计（底部 4 Tab：演练 / 学习 / 社区 / 我的），四大模块全部落地：

- **演练**：星星档案建档 → 一句话生成孪生场景 → 与「AI 孩子」实时演练 + 观察专家逐句点评 → 结构化总结报告
- **学习**：28 门循证干预方法课程、42 节互动课，讲师 Agent 三段式互动授课（讲解 → 提问 → 实战检验）
- **社区**：星友社区，话题分类、发帖、评论、点赞，专家答疑标识
- **我的**：孩子档案管理、学习/演练数据统计、每周干预周报（周报主编 Agent 生成）
- **登录**：微信一键登录 + 手机号验证码登录（小程序内接 `wx.login` / `getPhoneNumber`，Web 预览为演示通道）
- **积分**：新用户赠送 30 积分，演练 5 积分/场、课程 2 积分/节、周报 3 积分/期；
  积分中心含充值套餐与明细流水（小程序内接微信支付，iOS 端虚拟支付限制见部署手册）
- **语音与 AI 玩具**：语音层（ASR/TTS）与干预大脑解耦的级联架构；演练页支持语音朗读与语音输入；
  玩具端一站式端点 `POST /api/voice/turn`（听→想→说一次完成）+ 第 6 位专家「小星玩伴」Agent；
  声音模型选型、ESP32 硬件方案与接入协议见 [docs/VOICE_TOY.md](docs/VOICE_TOY.md)
- **开源选型**：玩具固件基于 xiaozhi-esp32 生态（29k★），语音支持 FunASR/CosyVoice 自部署切换；
  全链路采纳/不采纳决策清单见 [docs/OPENSOURCE_STACK.md](docs/OPENSOURCE_STACK.md)

## 设计系统

温馨调性的完整设计系统与案例调研见 [docs/design/index.html](docs/design/index.html)（浏览器直接打开）：

## 快速开始

```bash
cd xingtong-cat
npm install
export KIMI_API_KEY=...   # 模型网关密钥
npm run dev               # 开发服务器
```

环境变量：

| 变量 | 说明 | 默认 |
|---|---|---|
| `KIMI_API_KEY` | LLM 网关密钥（必填） | — |
| `KIMI_BASE_URL` | OpenAI 兼容接口地址 | `https://agent-gw.kimi.com/coding/v1` |
| `XINGTONG_MODEL` | 使用的模型 | `k3-agent` |
| `WX_APPID` / `WX_SECRET` | 微信小程序登录（无配置走本地模拟） | — |
| `DASHSCOPE_API_KEY` | 云端语音（阿里百炼，可选；不配则浏览器本地语音兜底） | — |
| `XINGTONG_TTS_MODEL` / `XINGTONG_TTS_VOICE` / `XINGTONG_ASR_MODEL` | 语音模型/音色覆盖 | cosyvoice-v1 / longwan / sensevoice-v1 |

```
app/                        Next.js 15 App Router 页面（移动端优先，小程序形态）
  page.tsx                  品牌落地页

  onboarding/               星星档案四步建档
  home/                     演练 Tab：孩子卡片 + 预置场景 + 自定义场景
  session/[id]/             孪生演练对话（孩子气泡 + 观察专家点评卡）
  report/[id]/              结构化总结报告（评分环/亮点/改进/孩子解读/下周练习）
  learn/                    学习 Tab：28 门课程（按孩子档案个性化推荐排序）
  learn/[courseId]/         课程详情：课时列表 + 完成进度
  learn/[courseId]/[lessonId]/  互动课：讲师 Agent 对话式授课 + 课时打卡
  community/                社区 Tab：话题流（全部/情绪崩溃/经验分享/专家答疑/互相取暖）
  community/[id]/           帖子详情 + 评论
  community/new/            发帖
  weekly/                   每周干预周报（数据汇总 + 主编 Agent 寄语）
  me/                       我的 Tab：档案、统计、周报入口
components/TabBar.tsx       小程序底部导航
components/NavBar.tsx       页面顶部导航
app/api/                    服务端 API（密钥不出服务器）
lib/agents.ts               ★ 多专家 Agent 矩阵（COSTAR Prompt 框架）
  ① 场景理解者      模糊描述 → 结构化场景
  ② 心理学检索者    本地知识库检索（RAG）
  ③ 自闭症儿童模拟者 以孩子视角真实回应（情绪强度 1-10 连续建模，动作用【】标注）
  ④ 互动观察心理专家 逐句教练式点评（与孩子模拟并行调用）
  ⑤ 协调总结专家    结构化报告（评分/亮点/改进/孩子解读/下周练习）
  ⑥ 循证课程讲师    teach/ask/readyToPractice 三段式互动授课
  ⑦ 周报主编        汇总一周数据生成温暖有洞察的周报
lib/knowledge.ts            知识库加载 + 关键词检索
data/knowledge/             干预知识语料 V0.1（8 篇：ABA、情绪共同调节、感觉统合、
                            视觉支持、社交故事、沟通促进、地板时光、场景库、DSM-5、专业边界）
lib/courses.ts              28 门循证课程 / 42 节互动课 + 按档案个性化排序
lib/store.ts                JSON 文件存储（data/store/，零依赖，可随时换数据库）
```

## 已验证的端到端链路

建档（乐乐，4 岁，ASD 中度）→「超市购物」场景 → 家长错误应对（威胁）→ 孩子情绪 5→9 真实升级、
专家指出「抛弃式威胁」问题并给示范说法 → 家长正确应对 → 孩子回落到 5 → 报告 74 分，
含亮点引用、改进示范、孩子解读与下周练习。讲师授课、课时打卡、周报生成、社区发帖/评论全链路通过。

## 内容边界说明

知识库语料与课程内容基于公开循证干预通识撰写，**未经专家顾问团审校**。
正式上线前需按路演计划由心理学/特殊教育专家审校全部语料。
